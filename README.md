# DUT Gym – Digital Fitness & Membership Management Platform

## Overview

DUT Gym is a digital fitness and membership management platform designed to enhance the gym experience for students at Durban University of Technology (DUT).

The application aims to modernise traditional gym membership processes while providing students with an interactive, personalised and engaging fitness experience. It combines digital membership management, fitness tracking, nutrition suggestions, gym capacity monitoring and gamification into one centralised platform.

The goal is to make fitness more accessible, convenient and engaging for students while encouraging healthier lifestyles and consistent participation in physical activity.

## Key Features

### 1. Digital Membership Management

* Digitalised gym membership registration and management.
* Centralised access to membership-related information.
* Simplified membership processes to improve convenience for students.

### 2. Personal Fitness Buddy

* Provides personalised fitness guidance and support.
* Offers nutrition suggestions based on users' fitness goals and preferences.
* Helps students stay informed and motivated throughout their fitness journey.

## Technology Stack

The application was developed using the following technologies:

| Technology      | Purpose                                                   |
| --------------- | --------------------------------------------------------- |
| C#              | Core application programming and backend logic            |
| ASP.NET         | Web application development and server-side functionality |
| HTML5           | Application structure and content                         |
| CSS3            | Styling and user interface design                         |
| JavaScript      | Client-side interactivity and dynamic functionality       |
| Local Database  | Data storage and management during local development      |


## System Architecture

DUT Gym follows a web-based application approach, combining server-side functionality with an interactive frontend.

* **Frontend:** HTML, CSS and JavaScript provide the user interface and interactive elements.
* **Backend:** C# and ASP.NET handle application logic and server-side processing.
* **Database:** A local database supports data storage and retrieval during development.
* **Deployment:** Microsoft Azure is used to host the deployed version of the application.

## Project Objectives

The application was developed to address several challenges associated with traditional university gym experiences:

* Reduce reliance on manual membership processes.
* Improve access to gym membership information.
* Help students make informed decisions about when to visit the gym.
* Encourage fitness consistency through goal tracking and gamification.
* Provide accessible fitness and nutrition guidance.
* Introduce a more convenient and digitally connected gym experience.

## Getting Started

To run the project locally:

### Prerequisites

* Visual Studio
* .NET SDK compatible with the project
* A compatible web browser
* Local database configuration used by the application

### Installation

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project directory:

   ```bash
   cd DUT-Gym
   ```

3. Open the solution file in Visual Studio.

4. Restore the required NuGet packages.

5. Configure the local database connection string and any required application settings.

6. Build and run the application using Visual Studio or the appropriate .NET CLI commands.

7. Open the local development URL displayed when the application starts.

## Project Value

DUT Gym demonstrates how technology can be used to improve everyday student experiences through digital transformation.

By bringing membership management, fitness guidance, goal tracking, gym capacity awareness and gamification together, the platform aims to create a more accessible, personalised and engaging fitness environment.

The project also demonstrates practical application of full-stack web development concepts, database integration, user-focused system design and cloud deployment.
